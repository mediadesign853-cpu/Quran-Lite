# قرآن ریدر لایت | Quran Reader Lite

**زبان‌ها:** [English](README.md) | **فارسی** | [العربية](README.ar.md)

**Quran Reader Lite** یک برنامهٔ دسکتاپ برای ویندوز است که با **Electron، React و TypeScript** ساخته شده و امکان مطالعه و جست‌وجوی متن عربی قرآن را بدون نیاز به اینترنت فراهم می‌کند. نسخهٔ Lite شامل متن عربی قرآن است و ترجمه یا تفسیر ندارد.

منبع متن قرآن: [tanzil تنزیل](https://tanzil.net) — مجوز CC BY 3.0.

## ✨ امکانات اصلی

- مطالعه و جست‌وجوی ۱۱۴ سوره و آیات قرآن.
- نمایش تصاویر ۶۰۴ صفحهٔ مصحف در نسخهٔ فعلی برنامه.
- ذخیرهٔ نشانک‌ها، تاریخچهٔ جست‌وجو و آخرین محل مطالعه.
- رابط کاربری فارسی و عربی، پوستهٔ روشن و تاریک و تغییر اندازهٔ متن.
- کپی آیات با امکان تنظیم شمارهٔ آیه، نشانه‌های قرآنی و نشانی آیه.
- درج پاورقی واقعی در **Microsoft Word** و **Adobe InDesign** در نسخهٔ دسکتاپ ویندوز.
- مطالعه و جست‌وجو به‌صورت آفلاین؛ دریافت به‌روزرسانی به اینترنت نیاز دارد.
- دو نسخه برای ویندوز: نصب‌کنندهٔ **NSIS** و نسخهٔ **Portable**.

## 📥 نصب و راه‌اندازی

۱. به [صفحهٔ آخرین انتشارها در GitHub](https://github.com/mediadesign853-cpu/quran-lite/releases/latest) بروید.

۲. یکی از فایل‌های زیر را دریافت کنید:

- **Quran Reader Lite Setup** — نسخهٔ نصب‌شونده؛ برای نصب معمولی پیشنهاد می‌شود.
- **Quran Reader Lite Portable** — بدون نصب اجرا می‌شود.

۳. فایل دانلودشده را اجرا کنید. در نسخهٔ Portable، پوشهٔ `Quran Reader Lite Data` را کنار فایل EXE نگه دارید؛ اطلاعاتی مانند تنظیمات و نشانک‌ها در این پوشه ذخیره می‌شوند.

### استفاده از Word و InDesign

درج پاورقی واقعی فقط در نسخهٔ دسکتاپ ویندوز در دسترس است. برنامهٔ مقصد، یعنی Word یا InDesign، باید روی ویندوز نصب باشد. اگر درج پاورقی انجام نشد، ابتدا برنامهٔ مقصد را باز کنید و دوباره تلاش کنید.

## 🔄 به‌روزرسانی خودکار

- برنامه پس از اجرا، وجود نسخهٔ جدید را بررسی می‌کند و این بررسی را به‌صورت دوره‌ای ادامه می‌دهد.
- پیش از دریافت به‌روزرسانی، از کاربر تأیید می‌گیرد.
- نسخهٔ نصب‌شده با NSIS از سازوکار به‌روزرسانی Electron استفاده می‌کند.
- نسخهٔ Portable اعتبار فایل به‌روزرسانی را بررسی می‌کند و سپس فایل برنامه را جایگزین می‌کند.
- برای دریافت به‌روزرسانی، اتصال اینترنت لازم است. در نسخهٔ Portable، پوشهٔ حاوی فایل EXE باید اجازهٔ نوشتن داشته باشد.

**نکته:** فایل‌های انتشار فعلی با گواهی ناشر Windows (Authenticode) امضا نشده‌اند؛ بنابراین ممکن است Windows SmartScreen هشدار «ناشر ناشناس» نمایش دهد. برنامه را فقط از [صفحهٔ رسمی انتشارها](https://github.com/mediadesign853-cpu/quran-lite/releases/latest) دریافت کنید.

## 🛠️ ساخت برنامه از کد منبع

این بخش برای توسعه‌دهندگانی است که می‌خواهند برنامه را از کد منبع بسازند. به **Node.js 22** و npm نیاز دارید.

دستورها را در پوشهٔ اصلی پروژه و در PowerShell اجرا کنید:

</div>

```powershell
npm ci
npm run check
npm run dist:win
```

<div dir="rtl" align="right">

- `npm run check` داده‌های قرآن، TypeScript، قواعد ESLint و ساخت برنامهٔ وب را بررسی می‌کند.
- `npm run dist:win` نسخه‌های ویندوز ۶۴ بیتی Setup و Portable را در پوشهٔ `release/` می‌سازد.

### انتشار نسخه در GitHub

انتشار خودکار از طریق GitHub Actions انجام می‌شود. گردش‌کار پروژه با Push کردن یک Tag که با `v` شروع شود، مانند `v1.0.1`، اجرا می‌شود. این فرایند بررسی‌های پروژه را انجام می‌دهد، فایل‌های ویندوز را می‌سازد و فایل‌های به‌روزرسانی را به انتشار GitHub اضافه می‌کند.

برای آماده‌سازی سامانهٔ به‌روزرسانی Portable، پروژه این دستورهای مدیریتی را نیز دارد:

</div>

```powershell
npm run generate:portable-keys
npm run verify:portable-key
npm run create:portable-manifest
```

<div dir="rtl" align="right">

**توجه توسعه‌دهندگان:** دستور `generate:portable-keys` فقط هنگام راه‌اندازی اولیهٔ سامانهٔ کلید اجرا می‌شود؛ برای هر انتشار کلید تازه نسازید. کلید خصوصی باید محرمانه بماند و در Git قرار نگیرد. جزئیات تنظیم Secrets و مراحل کامل انتشار در مستندات توسعه‌دهندگان نگهداری می‌شود.
